# CaptureInspiration

--------------------------------
*To capture your inspirations anywhere,anytime.*

YOU CAN USE IT TO MANAGER THE SUDDEN INSPIRATIONS

## Something important
The source code is based on SDL3 ,Freetype ,but it does not include them.<br>
So if you want to modify codes and compile them,remember include them.

- ENVIRONMENT
    - dear imgui, v1.92.9 WIP, <https://github.com/ocornut/imgui>
    - SDL3, version 3.4.12, for x86_64-w64-mingw32, <https://github.com/libsdl-org/SDL>
    - mingw64, MinGW-W64-builds-5.0.0, <https://www.mingw-w64.org/>
    - Freetype, 2.14.3, <https://freetype.org><br>
      (In this project,all External expansions of Freetype have been disabled)
    - JSON for Modern C++, version 3.12.0, <https://github.com/nlohmann/json>
    - Cmake, 4.4.1, <https://cmake.org/>
    - platform:windows(to hide taskbar,use windows.h)
